مشروع دعوة الزفاف — Mawadda
===========================

الملفات الرئيسية:
- index.html: بنية الدعوة والمحتوى.
- style.css: التصميم والحركات والتجاوب.
- script.js: فتح الظرف، الموسيقى، العد التنازلي، المشاركة، المعرض، ونموذج الرد التجريبي.

آخر التعديلات:
- إزالة الآيات من شاشة الظرف ومن القسم التالي في القالب الرومانسي.
- إضافة العبارة الشعرية على الورقة، وبيتين رومانسيين في القسم التالي.
- استبدال رابط تفاصيل المناسبة بإشارة «اسحب لأسفل لاكتشاف باقي التفاصيل» مع لمعة وسهم متحركين.
- الإشارة قابلة للضغط أيضًا وتنقل إلى القسم التالي.
- استمرار تجربة الصوت عند الضغط على ختم الشمع، مع زر دائري لإيقاف الموسيقى أو استئنافها.

التشغيل:
1. افتح مجلد المشروع في VS Code.
2. شغّل index.html باستخدام Live Server أو ارفع المجلد إلى استضافة ثابتة.
3. للموسيقى، ضع ملف MP3 مصرحًا لك باستخدامه داخل assets بهذا الاسم بالضبط:
   farha-mahmoud-el-esseily.mp3
4. إذا أضفت الملف بعد فتح الصفحة، حدّث الصفحة باستخدام Ctrl+F5.

ملاحظات:
- ملف الموسيقى غير مرفق بالمشروع؛ تأكد من حقوق الاستخدام والترخيص قبل نشره.
- أسماء العروسين والتاريخ والمكان بيانات تجريبية ويجب تحديثها.
- نموذج تأكيد الحضور تجريبي ولا يرسل أو يحفظ البيانات على خادم.
